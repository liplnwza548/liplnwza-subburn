# liplnwza-subburn — สกิลเบิร์นซับไทย (thai-subburn)

บริการเบิร์นซับไทยลงวิดีโอสำเร็จรูปของฟิลิป (standalone — คนละสกิลกับ Motion Kit ไม่เกี่ยวกัน)
ฟิลิปส่งวิดีโอที่ยังไม่มีซับมาให้ (บ่อยครั้งทีละ ~6 คลิป) งานคือใส่ซับให้ตรงเสียงและสวยตามเทมเพลตที่ล็อกไว้ แล้วส่งมอบเป็นไฟล์ใหม่ ต้นฉบับไม่ถูกแตะต้องเสมอ

## Workflow (A–F)

```
(A) รับงาน      ลิสต์ + คัดลอกวิดีโอจากโฟลเดอร์รับงานบน Drive เข้าพื้นที่ทำงาน (ทำงานบนสำเนา)
(B) ถอดเสียง    Groq whisper-large-v3-turbo เอาเวลาระดับคำของทุกคลิป
(C) ร่างบท      สร้างบทที่แก้แล้วจากเสียงจริง — เสียงชนะบทเสมอ แมปคลิปด้วยเนื้อหาที่พูด ไม่ใช่ลำดับไฟล์
(D) ⛔ STOP     ส่งร่างบททุกคลิปให้ฟิลิปอนุมัติ + ฟิลิปเลือกสไตล์ (viralpop / paper-chips) ห้ามเบิร์นก่อนขั้นนี้
(E) เบิร์น      ด้วยตัวเบิร์นที่ล็อกไว้ของสไตล์ที่เลือกเท่านั้น
(F) QC + ส่งมอบ ตรวจเฟรม + วัดความดังซ้ำทีละคลิป รายงานตัวเลขจริง ส่งมอบเป็นไฟล์ใหม่
```

รายละเอียดเต็มอยู่ใน [SKILL.md](SKILL.md) — อ่านให้จบก่อนเริ่มงานทุกครั้ง

## กฎเหล็ก (สรุป — ฉบับเต็มใน SKILL.md)

- เบิร์นด้วยตัวเบิร์น 2 ตัวใน repo นี้เท่านั้น — **ห้ามใช้ `ffmpeg -vf subtitles=` หรือวิธีอื่นเด็ดขาด**
- ฟอนต์ Prompt-Bold เท่านั้น, viralpop ต้องมีคีย์เวิร์ดสีเหลือง (3–6 คำ เป็นข้อความตรงตัวในบทที่อนุมัติ)
- **ห้ามเบิร์นแม้แต่คลิปเดียวก่อนฟิลิปอนุมัติบทและเลือกสไตล์** (ขั้น D)
- เสียงชนะบทเสมอ; เวลาทุกคำต้องมาจากการถอดเสียงจริง ห้ามประดิษฐ์/หารเฉลี่ย timing
- ข้อความบนจอทุกคำต้องมาจากบทที่อนุมัติ ห้ามแต่งคำใส่เอง
- ต้นฉบับห้ามเขียนทับ/แก้/ลบ — ผลลัพธ์เป็นไฟล์ใหม่ทุกชิ้น
- รายงาน QC ด้วยตัวเลขที่วัดจริงเสมอ (ขนาดภาพ / ความยาว / LUFS / TP / exit code ของตัวเบิร์น)
