# ตัวเบิร์นประจำ 13 สไตล์ (ฟิลิปอนุมัติครบ 2026-11-04)

ตัวเบิร์นชุดนี้คือตัวเดียวกับที่เบิร์นคลิป 01 ตรวจเฟรมจริงครบ 13 แบบแล้ว
(24.43 วิทุกไฟล์) — Agents ตัวอื่นโคลน repo นี้ไปแล้วเบิร์นได้เลย
โดยไม่ต้องขอไฟล์จากเครื่องบีนเพิ่ม

## 13 สไตล์

- `karaoke` — คาราโอเกะไล่เติมคำ (คำที่พูดแล้วเป็นสีมิ้นต์)
- `editorial` — สารคดีนิ่ง (แผ่นดำโปร่งแสง ข้อความนิ่ง)
- `highlighter` — แถบปากกาไฮไลต์ (แถบเขียวมะนาวใต้คำที่กำลังพูด)
- `reveal` — เผยคำทีละคำ (คำที่ยังไม่ถึงสีเทาจาง)
- `underline` — ขีดเส้นใต้วิ่งตามคำ (แถบเขียวใต้คำที่กำลังพูด)
- `minimal` — ตัวบางมินิมอล (ตัวขาวเล็ก เงาอ่อน ไม่มีแผ่นรอง)
- `frosted` — แคปซูลกระจกฝ้า (ตัวเข้มบนแคปซูลขาวฝ้า)
- `dualtone` — บล็อกสลับสี (คำสลับกล่องดำ/ขาว)
- `comic` — บับเบิลการ์ตูน (ฟองขาวขอบดำ ติ่งชี้กลางจอ)
- `luxury` — นิตยสารลักชูรี (ตัว serif ขาว เงาอ่อน)
- `terminal` — กล่องคอนโซล (ตัวเขียวบนกล่องดำ มีเคอร์เซอร์)
- `clay` — ตัวอักษรดินน้ำมัน (ตัวพาสเทล ขอบเข้ม + เงา)
- `wordpop` — คำที่กำลังพูดเด้งตัวใหญ่สีเหลือง (ต่างจาก viralpop ที่เน้นเฉพาะ keyword)

## กฎที่ล็อกไว้ในตัวเบิร์น

- โซนปลอดภัย TikTok: แถบซับ y 1100–1440 (STRIP_Y=1100, STRIP_H=340) ขอบล่าง 520px
- ท่อนละ 3–5 พยางค์ ห้ามตัดกลางคำ ห้ามจบท่อนด้วย "ไม่"
- ข้อความมาจากบทที่ฟิลิปอนุมัติเท่านั้น ห้ามแต่งคำใหม่
- วาดซับเป็นคำด้วย PIL + overlay ห้ามใช้ `ffmpeg -vf subtitles=` โดยตรง
- ไม่เขียนทับไฟล์เดิม สร้างไฟล์ใหม่ทุกครั้ง

## ข้อจำกัดที่ต้องรู้ก่อนใช้กับคลิปใหม่

ตารางนับพยางค์ (`SYLLABLES`) ในตัวเบิร์นตอนนี้ครอบคลุมเฉพาะศัพท์ของ
คลิป 01 เท่านั้น คำใหม่ที่ไม่มีในตารางจะ error ทันที ไม่เดา — ต้องเพิ่ม
จำนวนพยางค์ของคำใหม่ด้วยหูก่อนเบิร์นคลิปใหม่ทุกครั้ง

## วิธีใช้

```bash
python3 burn_styles.py --style karaoke --video IN.mov --script NN.txt \
    --mfa NN_mfa.json --out OUT.mp4 --syllable-chunks
```

อินพุต: วิดีโอต้นฉบับ, บทที่ฟิลิปอนุมัติแล้ว, เวลาระดับคำจาก MFA
(ดูวิธีจับเวลาใน SKILL.md หลักของ repo นี้)

## ฟอนต์

- ฟอนต์หลัก Prompt-Bold อยู่ใน `fonts/Prompt-Bold.ttf` ข้างตัวเบิร์นเลย
  เป็นไฟล์เดียวกับรอบที่ตรวจเฟรมผ่าน — ตัวเบิร์นจะหยิบไฟล์นี้ก่อน
  จึงได้เฟรมตรงกับตัวอย่างที่ฟิลิปอนุมัติ
- สไตล์ `luxury` ใช้ Noto Serif Thai Bold จากระบบ (`/usr/share/fonts/...`)
  ถ้าเครื่องนั้นไม่มีไฟล์นี้ ตัวเบิร์นจะถอยกลับไปใช้ Prompt-Bold แทน
  (หน้าตาจะต่างจากตัวอย่างลักชูรีเล็กน้อย)
